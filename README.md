# ワードウルフ 🐺

スマホ1台を参加者で回しながら遊ぶ「ワードウルフ」パーティーゲーム。
サーバー不要・完全クライアントサイドで動作する単一ページアプリ（React + Vite）です。

- 対象人数: 3〜10人
- ネットワーク通信なし（オフラインで動作）
- localStorage 不使用（状態はすべてメモリ内で管理）
- スマホ縦画面前提のダークテーマUI

## 遊び方

1. 全員に少しずつ違うお題が配られ、1人だけ違うお題の「ウルフ」がいます
2. お題について雑談（お題の単語をそのまま言うのは禁止）
3. 制限時間後、「ウルフだと思う人」に全員で投票
4. 最多票がウルフなら市民チームの勝ち、外せばウルフの勝ち
5. 同票なら延長弁明と再投票。再投票も同票ならウルフの逃げ切り勝ち
6. （オプション）逆転ルールONなら、追放されたウルフが市民のお題を当てると逆転勝利

議論中はランダムな第一発言者と質問カードが表示され、投票前には全員15秒の最終弁明があります。同じメンバーで連戦すると勝敗スコアを引き継ぎ、お題はカテゴリ内を使い切るまで重複しません。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run lint     # 静的解析
npm test         # ゲームロジックのテスト
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルド結果のプレビュー
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/App.jsx` | フェーズ管理（title → setup → reveal → discussion → vote → result）の state machine |
| `src/game.js` | お題割り当て・集計・勝敗判定のコアロジック |
| `src/topics.js` | お題データ（4カテゴリ × 25ペア = 100ペア）+ ミックス |
| `src/components/` | 各フェーズの画面コンポーネント |
| `src/styles.css` | ダークテーマ + パープル〜ピンクのUIスタイル |

## ゲーム設計上のポイント

- **お題確認**: 各プレイヤーは「渡してください」画面から始まり、お題は**押している間だけ**描画。指を離すと即非表示。次の人へ進む際もお題はDOMに残らないため、他人のお題が見える瞬間がありません。
- **投票**: 投票後すぐ次の人への受け渡し画面を挟み、投票内容が次の人に見えないようにしています。自分自身には投票できません。
- **お題の入れ替え**: どちらの語が市民側／ウルフ側になるかは毎回ランダム。同一セッションで同じペアが連続で出ないよう調整。
- **同票**: 延長弁明を挟んで候補者への再投票を実施。再び同票ならウルフの勝ち。
